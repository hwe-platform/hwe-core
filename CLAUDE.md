# Claude Code

Este repo forma parte del proyecto HWE. La documentación de referencia, las
historias de usuario y los estándares de código viven en el repo `hwe-tools`
(se conecta como git submodule — ver historia HU-003).

Antes de implementar código en `hwe-core`, consulta en `hwe-tools`:

- `docs/estandares/codigo.md`, `naming.md`, `commits.md`, `testing.md`,
  `herramientas.md` — estándares de código, nombrado, git y testing
- `historias/` — la historia de usuario (HU-XXX) que estés implementando
- `docs/decisiones/` — decisiones de arquitectura (DEC-XXX), en particular
  `DEC-007-repos.md` sobre por qué existen tres repositorios
- `.claude/agentes/code-builder.md` — flujo de trabajo del Code Builder
